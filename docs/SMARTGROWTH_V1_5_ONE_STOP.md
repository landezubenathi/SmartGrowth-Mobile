# Archived v1.5 guide (superseded)

The previous release supported an optional Firebase administrator seeder for five fictional accounts. **The seeder has been disabled in v1.7**. Do not follow older instructions to create Firebase test accounts.

See `SMARTGROWTH_V1_7_CLEAN_SEED.md` for the current design and migration notes. Already-created Firebase test accounts remain in your Firebase project unless an administrator intentionally deletes them; upgrading this repository never deletes user data.
